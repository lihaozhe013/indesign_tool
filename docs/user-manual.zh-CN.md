# Folio 中文使用手册

Folio 是一个 macOS 桌面排版工具。你在 Folio 中编写 Markdown、选择 InDesign 模板并发布。Adobe InDesign 负责实际排版。Folio 会优先生成可继续编辑的 INDD，并分别尝试生成 PDF 和逐页 PNG 预览。每次发布都会附带一份中文检查报告。

在 Folio 菜单栏选择 **Help > 使用手册 / User Manual**，可以打开本手册的 GitHub 页面。

## 使用前准备

- macOS，以及已安装并能正常启动的 Adobe InDesign 2026。
- 一份可以在 InDesign 中打开的 `.indd` 模板。模板不需要运行 Folio 脚本，也不要求事先写入角色标签。
- 若文章含本机图片，图片文件应保存在电脑上，并能从 Markdown 文件所在文件夹通过相对路径找到。

首次让 Folio 控制 InDesign 时，macOS 可能询问是否允许自动化控制。选择允许。如果之前拒绝了，可在 **系统设置 > 隐私与安全性 > 自动化** 中允许 Folio 控制 InDesign。

## 发布一篇文章

1. 在 Folio 编辑区编写文章，或选择 **打开 Markdown** 载入已有 `.md` 文件。
2. 选择 **InDesign 模板**，打开一份 `.indd`。Folio 会扫描页面、框架、样式、字体和图片链接，并自动判断哪些对象适合标题、正文和图片。
3. 查看模板识别结果和下方提示。提示通常表示 Folio 选了备用对象、创建了备用文本框，或某种样式、图片、字体需要检查。提示不会阻止发布。
4. 在 **输出位置** 选择一个新的 `.indd` 文件名。同名的 INDD、PDF、预览文件夹或检查报告已存在时，请选择另一个文件名。
5. 选择 **发布文章**。Folio 保存文章，让 InDesign 创建可编辑文档，再尝试导出 PDF 和每页预览。
6. 发布结束后打开 INDD 查看完整成品，并打开中文检查报告逐项处理提示。PDF 或部分页面预览没有生成时，成功生成的其他文件仍会保留。

例如，输出路径为 `稿件.indd` 时，Folio 会尽量生成：

- `稿件.indd`：可在 InDesign 中继续编辑的文档，是必须生成的交付文件。
- `稿件.pdf`：如果 PDF 导出成功则生成。
- `稿件-preview/`：保存成功生成的页面预览图，例如 `page-001.png`。某一页失败时，其他页仍可保留。
- `稿件-report.txt`：每次成功交付 INDD 都会生成的 UTF-8 中文检查报告。

如果 Folio 显示“已生成，存在需要检查的项目”，表示 INDD 已经生成。请先打开 INDD 和报告；这不等于所有图片、字体、PDF 和预览都没有问题。

## Markdown 文章

Folio 支持 frontmatter 中的 `title` 和 `subtitle`，以及标题、段落、引用、分隔线、粗体、斜体、链接、行内代码和图片。

```markdown
---
title: "海边的灯塔"
subtitle: "一段关于归航的短记"
---

## 黄昏时分

海风从堤岸吹来。远处的灯塔亮起，像一个**安静而坚定**的信号。

> 夜色落下以前，我们总能看见方向。

![海边灯塔](images/lighthouse.jpg "风暴过后的灯塔")
```

- 没有文章标题时，Folio 使用 Markdown 文件名；未保存的新草稿使用“未命名文章”。
- Frontmatter 标题和正文第一个一级标题相同时，正文中的一级标题不会重复显示。两者不同时，封面使用 frontmatter 标题，正文标题仍保留，并显示提示。
- 有副标题时，Folio 会优先使用封面上的副标题框；模板没有合适框时会尝试在输出副本中创建一个。
- 二级标题通常使用章节标题样式，三级及更深标题通常使用小标题样式。
- 列表会转换成带项目符号或序号的段落；表格会转换成以竖线分隔的行；代码块会保留文字但失去代码块样式。
- 多段引用会拆成多个引用段落。行内图片会从句子中拆开，成为单独图片；图片前后的文字仍会保留。
- 图片说明文字会保留。若图片路径不存在、地址不受支持或 InDesign 无法放置图片，正文会插入醒目的缺图提示，显示文件名和替代文字。
- 图片路径相对于已保存的 Markdown 文件，例如 `images/lighthouse.jpg` 对应 Markdown 文件旁的 `images` 文件夹。网络图片地址当前无法下载或放置。
- `author` 和 `language` 可以被解析，但当前版本不会把它们排到页面中。

## 给设计师的 InDesign 模板制作说明

本节可以直接发给设计师。设计师只需要使用 InDesign 完成版式并交付 `.indd` 文件。不需要了解程序，不需要安装插件，也不需要复制或运行任何脚本。Folio 会在每次选择模板时自动识别对象；设计师可以通过清楚的名称提高识别准确度。

### 先理解“占位框”

模板是一份已经设计好、但还没有正式文章内容的 InDesign 文档。

- **固定内容**是底色、线条、页眉、页码、品牌标识等。发布时这些设计会保留。
- **可变内容**是每篇文章都会变化的标题、副标题、正文和图片。设计师要在版面中预留能容纳这些内容的位置。
- **占位框**就是一个预留位置的 InDesign 文本框或图片框。它不是什么代码，也不是要印在页面上的特殊文字。比如，在封面上画一个空的文本框作为主标题位置；发布时 Folio 会把文章标题放进框里。
- 不要把 `{{title}}`、`[标题]`、`占位符` 之类的提示字当成 Folio 的识别方法。框的用途由名称、类型、所在页面和版面位置共同判断。
- **样式**是 InDesign 保存的一套外观设置，例如字体、字号、颜色、行距和段落间距。设计师用样式安排视觉风格；文章内容缺少对应样式时，Folio 会尽可能使用相近样式或 InDesign 默认外观。

设计时可以在框里放临时样稿来检查行距和换行，但交付前建议清空这些临时文字和图片。框本身需要留在页面上，框内内容可以为空。

### Folio 如何识别页面和框

Folio 优先使用模板中已有的 Folio 角色标签。如果文件没有这些标签，Folio 会根据名称自动匹配，不要求设计师写回标签。

名称匹配会忽略大小写、标点和空格，会识别常见中文名称，也会忽略类似 `正文 / Body` 的样式组前缀。比如 `Cover Title`、`cover-title`、`封面标题` 都可以成为封面标题的候选名称。建议使用下表中的推荐名称，减少 Folio 选错框的机会。

| 用途 | 推荐对象名称 | 可识别的其他名称示例 | 对象类型 |
| --- | --- | --- | --- |
| 封面主标题 | `Hero Title` | `Cover Title`、`Title`、`主标题`、`封面标题` | 文本框 |
| 封面副标题 | `Hero Subtitle` | `Subtitle`、`副标题`、`封面副标题` | 文本框 |
| 封面图片 | `Hero Image` | `Cover Image`、`封面图片`、`主图` | 图片框 |
| 正文主框 | `Article Flow` | `Main Text`、`Body Text`、`正文`、`正文流`、`主文本框` | 文本框 |

**对象类型要正确。** 标题和正文必须使用文本框；图片位置必须使用图片框。即使一个图片框叫 `Hero Title`，Folio 也不会把它当成标题框。模板里同一用途有多个相似对象时，Folio 会选择匹配分数较高的一个；分数相同会优先选择正确页面上的框，再比较框的面积和文档顺序。检查面板和报告会列出所选对象与多个候选项。

识别可信度分为三档：

- **高可信**：角色标签或名称准确对应推荐用途。
- **可能匹配**：名称有相似词语，或只在部分内容上相符。
- **自动兜底**：Folio 根据页面顺序、位置或框的大小选择了对象，或准备创建备用文本框。

低可信识别不会弹窗拦住发布。设计师可以先看结果，再通过改名、移动或缩放框逐步改善模板。

### 页面建议

较容易识别的模板通常包含两个普通页面：一页封面，一页正文起始页。

- 页面名包含 `Cover`、`封面` 或 `首页` 时，Folio 会优先把它用于封面。没有明显名称时，使用第 1 页作为封面。
- 页面名包含 `Article`、`正文` 或 `内容` 时，Folio 会优先把它用于正文。正文页上有正文流文本框时也会作为识别线索；找不到时会按页面顺序选择。
- 只有一页的模板也可以使用：Folio 会复制这页作为正文起始页原型。
- 多余的普通页面不会进入输出文档。若有结束页或封底，并且希望 Folio 保留，请把页面命名为 `Ending`、`End Page`、`Back Cover`、`结尾`、`结束页` 或 `封底`；已经带 Ending 角色标记的页面也会保留。
- 封面、正文或结束页上的其他装饰对象可以继续保留。输出文档从模板另存而来，原始模板文件不会被修改。

把需要重复出现在正文续页上的页眉、页码和装饰放在应用到正文页的父版（Parent Page，旧称 Master Page）上。新增正文页会沿用正文原型的父版，并尽量复用正文框的位置。如果装饰只画在普通第 2 页上，它不一定会出现在 Folio 后来增加的正文页上。

### 样式建议

样式名不是发布门槛。Folio 会用名称和对象类型识别下表样式；缺少某一种样式时仍会继续生成 INDD。

| 样式用途 | 推荐样式名称 | 缺少时的处理 |
| --- | --- | --- |
| 封面标题 | `ArticleTitle` | 保留标题框自身外观；新建标题框使用 InDesign 默认段落格式。 |
| 副标题 | `Subtitle` | 使用 `Body` 或 InDesign 默认外观。 |
| 章节标题 | `SectionHeading` | 优先用 `Subheading`，再用 `Body`。 |
| 小标题 | `Subheading` | 优先用 `SectionHeading`，再用 `Body`。 |
| 正文 | `Body` | 尝试使用另一种段落样式；没有可用样式时使用 InDesign 默认格式。 |
| 引用、图注 | `Quote`、`Caption` | 使用 `Body` 或默认段落格式。 |
| 强调、链接、代码 | `Emphasis`、`Link`、`Code` | 保留文字，跳过对应字符样式。 |
| 正文图、封面图 | `InlineImage`、`HeroImage` | 正常尝试放图，跳过对象样式。 |

把样式放在样式组中没有问题，例如 `正文 / Body`。如果电脑缺少模板使用的字体，InDesign 可能替换字体；报告会提示，发布后的 INDD 仍需在 InDesign 中检查。

### Folio 会自动补足和保留什么

- 没有找到封面主标题框时，Folio 尝试在封面安全区域上部创建一个标题框。
- 文章有副标题但模板没有副标题框时，Folio 尝试在标题框下方创建框。
- 没有合适正文主框时，Folio 优先使用正文页中最大且尚未分配的文本框；找不到时，会在正文页边距内创建一个框。
- 后续正文页尽量沿用正文原型的父版和正文框位置。
- 模板没有封面图片框时，Folio 不会额外造封面图片框，正文图片仍会正常尝试放置。
- 图片丢失或放置失败时，正文中的图片位置会显示缺图提示；图片说明仍会保留。
- 字体替换、样式缺失、内容差异、排版溢出、PDF 导出失败和部分 PNG 预览失败都会显示为提示。它们通常不影响 INDD 的交付。

### 建议的制作顺序

1. 先和委托方确认页面尺寸、横竖版、出血、品牌颜色、封面是否需要图片、正文是否需要页眉页码，以及标题和文章通常有多长。
2. 用 InDesign 完成视觉设计，给封面标题、副标题、封面图片和正文主框使用推荐名称，并确保它们是正确类型的框。
3. 在正文父版上放置要重复的装饰。给章节标题、正文、引用、图注和字符内容建立设计师需要的样式；不需要的样式可以暂缺。
4. 留下足够的文字空间，尤其是长标题、副标题、正文小标题、图注和续页。不要只用“标题”两个字判断框是否够高。
5. 清掉临时样稿文字和图片，保留可变内容框，保存为 `.indd`。
6. 在 Folio 选择这份模板，检查自动识别结果。如果选择不理想，回到 InDesign 改善对象名、框的位置或大小，再重新选择模板。
7. 用一篇短文和一篇长文进行实际发布，再检查 INDD、中文报告、实际生成的 PDF 和预览图。

### 如何用检查报告逐步改善模板

每次交付后打开 `稿件-report.txt`。报告会记录页面、框和样式的选择分数及候选项，也会列出备用框、样式降级、缺失图片、缺失字体、文本检查结果、排版溢出和实际生成的文件。

建议一次改一类问题：

1. 先处理封面标题和正文主框是否选对。如果报告显示“自动兜底”或候选框名称很相似，给目标框改成推荐名称。
2. 再处理框所在页面和尺寸。主标题框应放在封面，正文主框应放在正文页；框太小会使文字溢出。
3. 再处理样式替代。按报告中显示的降级方向，补充或调整 `Body`、章节标题、引用、图注等样式。
4. 最后处理字体、图片链接和细节排版。打开 INDD 检查换行、页数、图片裁切和装饰关系。

Folio 不会自动改写原始模板，也不会把识别结果写回模板。每次修改模板后，只需在 Folio 重新选择该文件并重新发布，不用运行任何脚本。

### 实际验收建议

使用一篇短文确认封面标题、副标题和正文进入合适位置；再使用一篇较长文章确认续页、父版装饰、正文框位置和溢出提示。文章可以包含中文、英文、粗体、引用、图片和图注。预览图用于快速检查，最终仍应在 InDesign 中打开 INDD 检查成品。

交付给委托方时建议提供：

- 最终 `.indd` 模板，以及模板使用的外部图片、标识等原始文件。
- 使用的字体名称，以及字体的交付或授权方式。
- 一份简短说明：页面尺寸、出血、封面是否放图、标题建议长度、是否有正文续页父版。
- 一份样稿的发布结果和 Folio 中文检查报告。

## 常见问题

### Folio 识别错了框

在 Folio 的模板识别结果中查看所选对象和候选对象。回到 InDesign，把正确文本框或图片框改成推荐名称，确认框类型和所在页面正确，然后重新选择模板。名称清楚通常比重新建文件或修改脚本简单。

### 模板缺少标题框或正文框

Folio 会尝试在输出副本中创建备用框。打开报告确认它使用了哪页和哪个默认位置。如果版式不合适，可在模板中建立并命名对应框，再重新发布。原模板不会被自动修改。

### 缺少样式或字体

缺少样式时，Folio 会使用相近样式或 InDesign 默认格式，并在报告中记录。缺少字体时 InDesign 可能替换它；安装或替换成双方都有的字体后，再重新发布检查。

### 图片未显示

检查图片文件是否存在、路径是否相对于已保存的 Markdown 文件正确，以及图片格式是否能被 InDesign 放置。发布仍会尽量生成 INDD，图片位置会显示缺图提示。修好路径后重新发布。

### 文章文字溢出

Folio 会根据 InDesign 的溢出状态尝试增加正文页并重新排版。长文、字体替换或较小的正文框仍可能造成溢出。报告会提示需要检查的内容；可以扩大正文框、调整字体和间距，或增加合适的父版设计后再发布。

### PDF 或某页 PNG 没生成

打开报告查看哪些附属文件成功。PDF 和每一页 PNG 分开尝试；它们的失败不会删除已经生成的 INDD，也不会删除其他成功的预览文件。

### InDesign 无法连接或模板打不开

确认 InDesign 2026 已安装、可以正常启动，并已允许 Folio 通过 macOS 自动化控制 InDesign。损坏或无法打开的 `.indd` 文件无法继续发布；请先在 InDesign 中打开并另存一份可用模板。

## 当前版本范围

- 支持本机 macOS 和 InDesign 2026。
- Folio 使用自动角色识别和可选的现有角色标签；设计师不需要运行脚本。
- 发布保证优先保留可编辑 INDD；PDF 和页面预览属于分别尝试的附属成果。
- Markdown 表格、列表和代码块会降级为普通文字；不支持的内容会尽量转换成可读文字。
- Folio 生成的页面 PNG 便于检查，不替代 InDesign 中的印前校对。
